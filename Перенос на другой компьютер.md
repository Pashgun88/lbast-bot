# Перенос AI__ на другой компьютер

Инструкция на день переезда: 29.10.2026. Репозиторий — `https://github.com/Pashgun88/lbast-bot.git`,
рабочая ветка **master**.

> **Ветка именно `master`.** В репозитории есть ещё `main`, но он разошёлся и отстал на 582 коммита —
> это старая ветка облачного агента. Весь живой код AI__ лежит в `master`.

> **Главное про два компьютера.** Пока AI__ запущен на старой машине, на новой его запускать нельзя:
> два драйвера под одним игровым аккаунтом дерутся за сессию и ловят ошибки игры. Порядок строгий:
> сначала выключить на старой (см. раздел 7), потом включать на новой.

---

## 1. Что везёт git, а что нет

В репозитории лежит **весь код**: драйвер, библиотеки `ai_char/lib/*`, маршруты квестов
`ai_char/guides/*.steps`, скрипты запуска и сторожа, замеры (рыбалка, опыт, аукционы).

Git **не хранит** (и правильно делает) четыре вещи, без которых AI__ не поедет:

| Что | Где лежит | Зачем нужно |
|---|---|---|
| Секреты | `.env` в корне | токен и chat_id Telegram |
| Сессия в игре | `ai_char/chrome-profile-ai-char/` | иначе драйвер не залогинен |
| Состояние персонажа | `ai_char/daily_quests_piraty.state.json` | дни дейликов, счётчики, слот задания |
| Прогресс маршрутов | `ai_char/guides/guides_state.json` и `ai_char/guides/*.progress` | многодневные квесты не начнутся заново |

Плюс по желанию — `ai_char/chat_memory/` (долгая память разговоров в клановом зале; без неё AI__
просто забудет, кто о чём говорил).

**Не переносить:** `driver_live.log`, `driver_err.log`, `driver_cycle.heartbeat`, `tg_dedup.json`,
`restart_log.txt`, `restart_storm_notified.txt`, `watchdog_last_run.txt`, `recon.flag` — это
локальные журналы, у каждой машины свои.

**Ни в коем случае не трогать** `daily_quests_piraty.state.json` **в корне** — это состояние
Цунами, на новой машине оно своё и живое.

## 2. Что должно стоять на новой машине

- **Node.js 22** (здесь v22.21.0);
- **Git for Windows** — он нужен не только для git: и `recon_start.ps1`, и сторож запускают драйвер
  через `C:\Program Files\Git\bin\bash.exe`. Если Git встанет в другую папку, путь придётся
  поправить в `ai_char\recon_start.ps1` и `ai_char\keep_driver_alive.ps1`;
- **Claude CLI** (`claude` в PATH Git Bash, с выполненным входом) — через него отвечает чат AI__
  (`chat_autoreply.js`). Без него бот живёт и воюет, но в клановом зале молчит.

## 3. Куда класть папку

Проект ждёт себя по пути **`C:\lbast-bot`**. Этот путь зашит в:

- `ai_char\keep_driver_alive.vbs` — полный путь к скрипту сторожа;
- `ai_char\keep_driver_alive.ps1` и `ai_char\recon_start.ps1` — строка запуска `cd /c/lbast-bot/ai_char`;
- разведочные скрипты `ai_char\_*.js` — путь к профилю Chrome.

Проще положить по тому же пути, чем править десяток файлов.

**Если на новой машине бот Цунами уже лежит в `C:\lbast-bot`** — а он, скорее всего, лежит именно
там, потому что `manager_bot.js` и `daily_quests_piraty.js` живут в этом же репозитории, — то
переносить нечего: это та же папка, просто обнови её.

```powershell
cd C:\lbast-bot
git status            # посмотреть, нет ли там своих незакоммиченных правок Цунами
git fetch origin
git checkout master
git pull origin master
```

Если `git status` показывает чужие правки — **не затирать**: сначала покажи их мне или закоммить,
потом тяни.

Если папка не под git (просто копия файлов) — клонируй репозиторий рядом, например в
`C:\lbast-bot-new`, перенеси туда локальные файлы Цунами и переименуй папки. Так ничего не теряется.

Если же папки нет вовсе:

```powershell
git clone https://github.com/Pashgun88/lbast-bot.git C:\lbast-bot
cd C:\lbast-bot
git checkout master
```

## 5. Перенести руками четыре вещи

Со старой машины на новую, в те же пути:

1. `C:\lbast-bot\.env` — две строки, `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
   Их же использует бот Цунами, так что если на новой машине `.env` уже есть — не перезаписывать,
   а сверить, что обе строки на месте.
2. `C:\lbast-bot\ai_char\chrome-profile-ai-char\` — папку целиком, при **выключенных** драйвере и
   Chrome (иначе скопируются файлы блокировки).
   Не получилось — не беда: запусти `node ai_char\open_browser_ai_char.js`, войди в игру под AI__
   руками один раз и закрой окно — сессия останется в профиле. Пароль AI__ в код не вписывать.
3. `C:\lbast-bot\ai_char\daily_quests_piraty.state.json`.
4. `C:\lbast-bot\ai_char\guides\guides_state.json` и все `ai_char\guides\*.progress`.

По желанию — `ai_char\chat_memory\`.

## 6. Сторож в планировщике

Драйвер иногда висит, и его поднимает внешний сторож — задача Windows, которая раз в 5 минут
запускает `keep_driver_alive.vbs`. На новой машине её надо создать:

```powershell
$action  = New-ScheduledTaskAction -Execute 'wscript.exe' -Argument '"C:\lbast-bot\ai_char\keep_driver_alive.vbs"'
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Minutes 5)
$set     = New-ScheduledTaskSettingsSet -ExecutionTimeLimit (New-TimeSpan -Minutes 5) -MultipleInstances IgnoreNew
Register-ScheduledTask -TaskName 'lbast-ai-char-keepalive' -Action $action -Trigger $trigger -Settings $set -Description 'Поднимает драйвер AI__, если он завис или упал'
```

Проверить, что задача живёт и отрабатывает:

```powershell
Get-ScheduledTask -TaskName 'lbast-ai-char-keepalive' | Get-ScheduledTaskInfo
Get-Content C:\lbast-bot\ai_char\watchdog_last_run.txt   # время последнего захода сторожа
```

## 7. На старой машине — выключить

Пока не сделано, на новой не запускать.

```powershell
cd C:\lbast-bot\ai_char
powershell -ExecutionPolicy Bypass -File .\recon_stop.ps1      # ждёт конца боя, потом гасит
Disable-ScheduledTask -TaskName 'lbast-ai-char-keepalive'      # иначе сторож поднимет драйвер снова
```

`Disable` — не удаление: если переезд сорвётся, задача включается обратно одной командой
`Enable-ScheduledTask`.

## 8. Запуск на новой машине

```powershell
cd C:\lbast-bot\ai_char
powershell -ExecutionPolicy Bypass -File .\recon_start.ps1
```

Скрипт сам погасит лишние копии, снимет блокировки профиля Chrome и напечатает PID нового драйвера.

Что проверить в первые десять минут:

```powershell
Get-CimInstance Win32_Process -Filter "Name='node.exe'" | Where-Object { $_.CommandLine -like '*driver.js*' } | Select-Object ProcessId, CreationDate
Get-Content C:\lbast-bot\ai_char\driver_live.log -Tail 40
```

Признаки, что всё поехало:

- в журнале идут строки `===== CYCLE N/Infinity =====` и `stats: { hpCurrent: … }`;
- обновляется файл `ai_char\driver_cycle.heartbeat` (это пульс главного цикла, по нему судит сторож);
- нет строки «Нет сохранённой сессии» — если она есть, значит не доехал профиль Chrome (пункт 5.2);
- в Telegram не сыплются ошибки.

Остановить в любой момент — `recon_stop.ps1` из той же папки.

## 9. Что учесть рядом с ботом Цунами

Они уживаются, если помнить про четыре разделения:

1. **Профили Chrome разные:** Цунами — `chrome-profile\`, AI__ — `ai_char\chrome-profile-ai-char\`.
   Один профиль не терпит двух процессов, разные — живут спокойно.
2. **Состояния разные:** Цунами — `daily_quests_piraty.state.json` в корне, AI__ — файл с тем же
   именем, но в `ai_char\`. Перепутать их — потерять день дейликов у обоих.
3. **Telegram общий:** токен и chat_id одни, сообщения обоих ботов приходят в один чат. AI__ пишет
   туда только про поломки сценариев.
4. **Машина тянет два headful-Chrome**: это два окна браузера и два процесса node. Если новая машина
   слабее — лучше не ставить обоим фарм на одно и то же время.

Файлы Цунами (`manager_bot.js`, `daily_quests_piraty.js`, корневое состояние) драйвер AI__ не
импортирует и не трогает — проверено, это отдельный набор скриптов.

## 10. Если что-то не поехало

| Признак | Причина | Что делать |
|---|---|---|
| «Нет сохранённой сессии…» | не доехал профиль Chrome | пункт 5.2 — скопировать папку или войти руками |
| `page.goto: Timeout` подряд | нет сети или игра легла | подождать; сторож поднимет сам |
| Драйверов больше одного | запустили дважды | `recon_start.ps1` сам гасит лишние — просто запусти его |
| Сторож молчит, драйвер лежит | задача не создана или падает | `watchdog_last_run.txt` и журнал: сторож пишет туда причину |
| В клановом зале AI__ молчит | нет `claude` в PATH Git Bash | поставить и залогинить Claude CLI |
