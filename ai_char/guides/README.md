# Квесты по маршрутам: как AI__ проходит квесты без человека

Эта папка — способ, которым квесты lbast.ru превращаются в скрипт. Квест описывается не кодом, а
**файлом шагов** (`*.steps`): что нажать и в каком порядке. Выполняет файл один общий раннер
(`guide_run.js`), он же сам лечится, дерётся и останавливается, если игра разошлась с маршрутом.
Повторяемые квесты подключены к циклу драйвера через `quests.js`.

## Путь квеста: от гайда до цикла драйвера

1. **Исходник.** Берём пошаговое прохождение из ЖГ игроков (kate2008, Dikaya) или из подсказки
   в клановом зале. Сырой текст кладём в `src/*.txt` (например `src/krysha.txt`).
2. **Разведка.** Гайды описывают игру словами, а кнопки на экране бывают другими. Проверяем
   каждый экран вживую утилитой `look.js`: она открывает страницу, при необходимости нажимает
   цепочку ссылок и печатает экран и все ссылки. Драйвер на это время останавливаем: у Chrome
   один профиль.
   ```
   node guides/look.js city:2 "Магазин" "Лавка боевых ресурсов"
   node guides/look.js url:pers.php
   ```
3. **Файл шагов.** По разведке пишем `имя.steps` (синтаксис ниже). Всё, что гайд говорит
   словами, но кнопкой не является, в шаги не попадает. Пример: «Идти на главную улицу» в
   Мисттоуне на самом деле «Идти на запад».
4. **Разовый прогон.** `node guides/guide_run.js guides/имя.steps` в своём окне браузера.
   Раннер печатает каждый экран, после каждого шага пишет прогресс в `имя.steps.progress` и при
   повторном запуске продолжает с того же места. Лог прогона сохраняем в `имя_run.log`.
5. **Правка по живому прогону.** Расхождение (`mismatch`) — это новый экран, которого не было в
   гайде. Смотрим дамп, дописываем шаг, запускаем с того же места.
6. **В цикл драйвера.** Если квест повторяемый (Штольни каждый день, Смерть ростовщика раз в
   15 дней), его запись добавляется в `GUIDE_QUESTS` в `quests.js`. Драйвер вызывает
   `runGuideQuestsIfDue()` в каждом цикле, а `quests.js` сам решает, пора ли: смотрит меню Q,
   период и паузу после сбоя. Состояние хранится в `guides_state.json`.

## Синтаксис файла шагов

| Строка | Что делает |
|---|---|
| `# ...` | комментарий |
| `текст` | нажать ссылку, текст которой начинается с этого (регистр, «ё», кавычки, `*`/`•`/`-` в начале не важны) |
| `?текст` | то же, но необязательно: нет ссылки — шаг пропускается |
| `*текст` | жать, пока ссылка есть на экране (длинные рассказы из «Далее») |
| `@city N` | амулетом в город: 1 Последний портал, 2 Стоунгард, 3 Эвилгард, 4 Кулак Хаоса, 8 Девтаун, 9 Дорожный крест |
| `@heal 0.95` | лечиться **на месте** до доли от максимума HP; при висящем бое пропускается (HP тогда не растёт) |
| `@fight` | бой: проверка HP (по умолчанию 70%), «В бой!» / «Принять бой» / «Напасть», затем общий `fightLoop` с эликсиром из подсумка |
| `?@fight` | бой, если он появился (засады) |
| `@qinfo Имя` | открыть [инфо] квеста в меню Q |
| `@autolone` | дальше самому нажимать единственную ссылку сцены (кроме боя и отказа) |
| `@stop текст` | остановиться намеренно и написать письмо |

Раннер сам нажимает одиночное «Далее», если нужного шага ещё нет на экране: гайды пропускают
повествовательные экраны. После поездки на коне или амулетом он ждёт окончания «В пути».

Результат `runGuide()`: `done` / `mismatch` (нужного шага нет) / `lost` (бой проигран) /
`nofight` (ждали бой, кнопки нет) / `stop` / `error` (например, сайт не ответил).

## Правила, выученные на живых прогонах

- **С локации посреди квеста не уходить.** Засады и охрана выставляются заново, если уйти и
  вернуться (банкир у асассинов, псы у картины). Лечимся на месте: `@heal`, а в JS-квестах
  `questFightHpGate(..., { waitForRecovery: true })` — ждёт HP во второй вкладке, не трогая сцену.
- **Висящий бой HP не лечит.** Если на экране уже «В бой!», ждать бесполезно: нужно драться.
- **Перед тяжёлым боем полное HP**, а не порог 70% (Штольни, бой 2: Доктор + Здоровяк 2 на 1).
- **Эль только против сильных ботов.** Праздничный эль пьётся перед Штольнями, не в каждом цикле.
- **После боя не выходить «В игру»**, пока идёт рассказ: квест не засчитывается. Дожимать `*Далее`.
- **Слот задания один на всех.** «Вы ещё не выполнили другое задание» значит, что слот занят
  (Штольни, Колодец Страха, асассины делят его). Отказ (`pers.php?mod=dropquest`) делаем только по
  решению владельца.
- **Кириллица в регулярках — явными классами**: `\w` и `\b` в JavaScript видят только ASCII.
